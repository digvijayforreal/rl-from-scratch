The PPO loop

update 0

Every update repeats these four steps. The highlighted step is what the trainer is doing right now.

  1. 1

    Collect experience

    Play all games in parallel and record every move.

    The network picks moves by sampling from its probabilities, so it keeps exploring. Each step stores the board, the move, its probability, the reward and the value guess.

  2. 2

    Score every move (GAE)

    Advantage = how much better a move turned out than expected.

    At = δt + γλ·At+1,   δt = rt + γ·V(st+1) − V(st)

    Walks backwards through the rollout. Positive advantage: the move led to more reward than the value head predicted, so make it more likely.

  3. 3

    Update the brain

    Several passes of gradient descent on the clipped loss.

    L = −min(ρ·A, clip(ρ, 1±ε)·A) + cv·(V−R)² − ce·H

    ρ is how much more likely the move is now than when it was played. Clipping at 1±ε stops one update from changing the policy too much. The value term teaches the critic; the entropy term H keeps exploring.

  4. 4

    Share and repeat

    The live players get the new weights, the learning rate shrinks a little, and the loop starts again.

The brain, thinking live

Watching:

The signal flows left to right. Input: the 8 layers of the board the network sees. Conv 1/2: feature maps, brighter = that filter found its pattern there. Hidden: 128 neurons combining everything. Output: one probability per move plus the value (how good the situation looks). Lines show the hidden neurons pushing hardest for the chosen move: blue pushes for it, red against. Hover anything for details.

What conv 1 looks for

Each 3×3 tile is one learned filter applied to one board layer. Red = "I like this object here", blue = "I don't". They start as noise and turn into edge and position detectors.

Weight distributions

A histogram of every weight in each layer. Watch them spread out as the network learns. A collapse to zero or runaway growth is a warning sign.

Layer health

Gradient size (how hard each layer is being pushed this update) and relative weight change (how much it actually moved). Layers that stop moving are losing plasticity.
